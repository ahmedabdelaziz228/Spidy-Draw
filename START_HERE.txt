─────────────────────────

2. Copy Python modules to server
3. Access web UI at device IP

──────────────────────

2. Select preset mode (logo, signature, fine-art, outline)
3. Preview paths
4. Generate G-code
5. Execute on hardware

COORDINATE SYSTEM
================================================================================

Important: Know the coordinate system before using!

Origin:    (0, 0) at TOP-LEFT of workspace
X-axis:    Increases LEFT → RIGHT
Y-axis:    Increases TOP → BOTTOM
Units:     Millimeters throughout
Workspace: 200×200mm total
Safe Area: 160×160mm (20mm margin from edges)
Precision: 3 decimal places (0.001mm)

If your drawings look upside down or rotated, check this!

================================================================================
PRESET MODES
================================================================================

Choose the right mode for your image:

LOGO MODE
─────────
Best for: Simple logos, icons, clean shapes
Features: High simplification, heavy blur
Result: Clean, minimal paths

SIGNATURE MODE
──────────────
Best for: Handwriting, signatures
Features: Medium simplification, detail preserved
Result: Natural-looking signatures

FINE-ART MODE
──────────────
Best for: Detailed drawings, complex images
Features: Minimal simplification, all details kept
Result: High-detail reproduction

OUTLINE MODE
─────────────
Best for: Contours only, no fills
Features: Aggressive simplification, clean contours
Result: Clean outlines only

CRITICAL BUG FIX
================================================================================

This project FIXES a critical bug in the original firmware:

PROBLEM:  Drawings didn't scale to fit workspace (hardcoded scale = 1.0)
SOLUTION: Added GCodeValidator for proper dynamic scaling
RESULT:   Drawings now correctly fit within 200×200mm workspace

If you're updating existing firmware, you MUST integrate:
  • include/gcode_validator.h
  • Modified gcode_executor.h and gcode_executor.cpp

================================================================================
QUICK TROUBLESHOOTING
================================================================================

Issue: "Image upload fails"
Solution: Check image is JPG or PNG, not too large

Issue: "Paths don't look right"
Solution: Try different preset mode, adjust parameters

Issue: "G-code generation fails"
Solution: Check path count isn't too high (max ~5000 points)

Issue: "Robot draws outside bounds"
Solution: This was fixed! Update your firmware with gcode_validator.h

Issue: "Output doesn't match preview"
Solution: Check coordinate system matches (origin, axes, scale)

See USER_GUIDE.md for more troubleshooting.
